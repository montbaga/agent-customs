What this site added

Main Street Guide was made with Cognizant's agentify-website kit, the way any agentic site is. To get the guard, it did two things.

  1. 1
    Copied one folder. customs/ from Agent Customs, next to the runtime/ folder the kit gives every site.
  2. 2
    Added two lines to site.js. An import at the top, and one call right after boot().

It changed no runtime file and runs no server. Everything else on this page is the kit's usual work.
